> Map every food resource within transit distance. SNAP eligibility screening. Meal planning on budget. Food bank logistics optimization.

## The Solution

**ResourceMapper** — Grocery stores, food banks, community gardens, SNAP farmers markets, free meal sites within transit distance\n**SNAPScreener** — Eligibility checker and application assistant for SNAP, WIC, and state programs\n**MealPlanner** — Budget-aware meal planning using available ingredients and local prices\n**FoodBankOptimizer** — Match surplus donations to highest-need locations in real-time\n**GardenGuide** — Community garden plots, seasonal planting guides by ZIP code

## Agents

No safety-critical decisions. Connects to existing government programs and community resources.
